# AIRAC Brasil - Releases & Distribuição ✈️🇧🇷

Bem-vindo ao repositório oficial de download e releases do **AIRAC Brasil**. 

O **AIRAC Brasil** é um utilitário desktop desenvolvido para automatizar a atualização de dados aeronáuticos e malhas de waypoints no simulador **X-Plane (11 e 12)** a cada ciclo AIRAC de 28 dias, com apenas um clique.

---

### 📥 Como Baixar

Para baixar a versão mais recente do aplicativo:
1. Acesse a aba **[Releases](https://github.com/piter4422/airac-brasil-releases/releases)** na barra lateral direita deste repositório.
2. Na versão mais recente (ex: `v1.0.0`), faça o download do arquivo executável (`AIRAC-Brasil.exe` ou `.zip`).
3. Siga as instruções de uso fornecidas no arquivo ou no nosso servidor do Discord.

---

### 📋 Requisitos e Compatibilidade
* **Simuladores suportados:** X-Plane 11 e X-Plane 12.
* **Sistemas operacionais:** Windows 10 / 11 (64-bit).
* **Navegação:** Compatibilidade nativa com FMC padrão, GPS G1000 e aeronaves que utilizam a base `Custom Data`.
